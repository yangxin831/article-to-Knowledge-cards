# 测试报告

对 `make-knowledege-cards` 按 SKILL.md 流程执行 4 类文章测试，结果如下。

## 测试结果

| 用例 | 文章类型 | 产出卡片数 | 结论 |
|------|----------|-----------|------|
| 01-https-长文.md | 科技类长文（信息充足） | 7 张 | 通过：数量在 5-8 内；一卡一点；例子与自测混合 |
| 02-四象限-方法短文.txt | 方法类中短文 | 6 张 | 通过：框架拆分合理；自测题均带答案要点 |
| 03-爬山日记-信息不足.txt | 纯叙事日记 | 0 张 + 说明 | 发现规则冲突（见下），已修订 |
| 04-早起-重复内容.txt | 重复重述多的文章 | 5 张 | 通过：同一观点换说法 3 次被归并为 1 张；未凑数 |

## 发现的问题与修订

1. **纯叙事文本无知识点，与"信息不足出 1-4 张"冲突**：强行出卡会违反"不凑数、不编造"。
   → 修订 Step 4：信息不足时出 0-4 张，完全无知识点时出 0 张并说明；输出规则补充 0 张时的说明格式。
2. **标题 8-20 字与英文术语冲突**：如"HTTPS 本质是 HTTP over TLS"超字数限制。
   → 修订为 8-24 字为宜，含英文术语时以准确简洁优先。
3. **简明解释易引入原文外推断**：初稿中出现"用这个标准复盘一天"等引申，自查时删除。
   → 自检清单改为"卡片全部内容（含简明解释和例子）都能在原文找到依据，无编造、无原文之外的推断"。

## 验证要点抽查

- 忠于原文：4 个用例逐卡核对，均可回溯到原文语句，无编造。
- 去重：用例 04 中"早起=成功/复利/零成本投资"等 3 处重述未单独成卡，归并入卡片 1-3。
- 一卡一点：用例 02 将"四象限处理策略"作为一张卡（一个映射知识），未拆成 4 张薄卡。
- 不凑数：用例 03 输出 0 张卡并说明原因。
